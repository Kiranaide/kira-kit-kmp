# AGENTS.md — Kira Kit KMP

## Project Overview
`kira-kit-kmp` is the Kotlin Multiplatform / Compose Multiplatform port of **Kira Kit V2**.
It targets **Android**, **iOS**, and **JVM Desktop** (used as the fast Compose Hot Reload sandbox).

## Architecture Rules
1. **No Material 3 dependency in library modules**: Build components in `:kira-components` directly on `compose.foundation` + **Compose Unstyled** (`com.composables:composeunstyled-primitives`). Never pull `material3` into `:kira-theme` or `:kira-components`.
2. **Design tokens are generated, not hand-edited**:
   - `kira-theme/src/commonMain/kotlin/com/kirakit/theme/KiraTheme.kt` and `tokens/kira-tokens.json` are generated by `bun run export:kmp` in `kira-kit-v2`.
   - Extend `KiraTheme` in separate files (`KiraTypography.kt`, `KiraSpacing.kt`, `KiraMotion.kt`) so re-exporting `KiraTheme.kt` never clobbers hand-written theme extensions.
3. **AGP 9+ Multiplatform Layout**:
   - Library/shared modules (`:kira-theme`, `:kira-components`, `:gallery`) use `com.android.kotlin.multiplatform.library` with `kotlin { android { ... } }`.
   - `:androidApp` is a standalone `com.android.application` module.
4. **Explicit Compose Dependencies**:
   - Compose Multiplatform 1.10+ removed `compose.*` dependency shortcuts. Always declare explicit Maven coordinates in `gradle/libs.versions.toml` (except `compose.desktop.currentOs` for JVM desktop).
5. **Selective Native Escape Hatches**:
   - Keep ~90% of components pure Compose in `commonMain`.
   - Use `expect`/`actual` only for platform-sensitive behaviors (e.g., `KiraHaptics`, native share sheets, iOS Liquid Glass overlays via `UIKitViewController(placedAsOverlay = true)`).
6. **Accessibility & UX**:
   - Interactive components must declare proper semantics (`Role.Button`, `Role.Checkbox`, `Role.Switch`, etc.), respect `enabled` state, animate state transitions with `KiraMotion`, and maintain touch target minimums (`>= 44.dp` default).

## Build & Verification Commands
> **Windows JDK note**: Ensure `JAVA_HOME` points to JDK 17 or 21 (e.g. `C:\Program Files\Java\jdk-21`), not JDK 11.

```bash
# Run unit tests (JVM)
./gradlew :kira-theme:jvmTest :kira-components:jvmTest

# Compile all JVM + Android targets
./gradlew :kira-theme:build :kira-components:build :gallery:compileKotlinJvm

# Launch Desktop Gallery (fast iteration & Compose Hot Reload)
./gradlew :gallery:run

# Publish library modules to local Maven (~/.m2/repository)
./gradlew :kira-theme:publishToMavenLocal :kira-components:publishToMavenLocal
```
